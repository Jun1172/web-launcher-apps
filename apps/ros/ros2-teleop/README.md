# 🎮 机器人遥控 (ros2-teleop)

通过 Web 界面控制 ROS2 机器人移动。

## 应用行为
- 虚拟摇杆控制（方向键 + 鼠标点击）
- 键盘支持（W/A/S/D 移动，空格停止）
- 可调速度滑块
- 发布速度指令到 `/cmd_vel` 话题

## 验证步骤
1. 启动仿真环境：`ros2 run turtlesim turtlesim_node`
2. 在 Launcher 中点击「机器人遥控」
3. 使用方向键或鼠标控制乌龟移动
4. 调整速度滑块改变移动速度

## 依赖
- ROS2 Humble 或更高版本
- 需要订阅 `/cmd_vel` 话题的机器人或仿真器
